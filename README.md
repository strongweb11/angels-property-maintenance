# Angels Property Maintenance and Services

Static website. Open index.html or serve this directory with any static web host.

All images, fonts and scripts are included. No ChatGPT sign-in is required by these files.

The quote form is a preview only and does not send email. Phone and email links are active.

For GitHub Pages, select Settings > Pages > Deploy from a branch > main > / (root), if Pages is available for this repository.
